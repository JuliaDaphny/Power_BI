## O que você encontra

| Arquivo | Conteúdo |
| --- | --- |
| `Painel de dados.pbix` | Arquivo do relatório para abrir no Power BI Desktop |
| `Extrato de vendas de uma empresa.xlsx` | Planilha de vendas utilizada no projeto |
| `Proposta.docx` | Documento de proposta que acompanha o projeto |

## Como explorar

1. Acesse o painel publicado para conhecer as visualizações.
2. Para examinar o relatório editável, baixe o arquivo `.pbix` e abra no Power BI Desktop.
3. Se houver solicitação de atualização da fonte, ajuste o caminho da planilha Excel para a sua cópia local.

O endereço do relatório e a imagem acima foram preservados da documentação original. A disponibilidade do painel depende do serviço Power BI.
